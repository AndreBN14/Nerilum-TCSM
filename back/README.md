# Backend pendiente

Actualmente no hay una API FastAPI implementada. Flutter usa Supabase Auth directamente.

Estas variables están preparadas para la futura API, pero todavía no hay un proceso que las cargue.
No hace falta contraseña PostgreSQL ni `service_role` para el login móvil.
Los modelos, endpoints y tablas de análisis se definirán en otra etapa.
